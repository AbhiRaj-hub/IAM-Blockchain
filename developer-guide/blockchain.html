7. Python Blockchain Service

What is a Blockchain?

A blockchain is an append-only chain of blocks where each block contains:

  • index: Sequential block height (0 = Genesis).
  • timestamp: Unix timestamp of when the block was created.
  • transactions: List of state changes (DID issuance, Access Grants, Hashes).
  • previous_hash: Cryptographic hash of the preceding block.
  • nonce: Proof-of-Work counter.
  • hash: SHA-256 digest of all block contents.

Why Is It Hard to Tamper with Previous Blocks?

Because Block #3 contains the hash of Block #2: if an attacker modifies data in Block #2, Block #2's hash changes. This breaks the link in Block #3, Block #4, and so on. The cryptographic integrity check chain.is_chain_valid() immediately detects this break!

Python Blockchain Structure

  • blockchain.py: Implements Block, Blockchain, Proof-of-Work mining, and is_chain_valid().
  • models.py: Transaction factory functions for IDENTITY_ISSUE, ACCESS_ATTEMPT, ASSET_ANCHOR, etc.
  • api.py: Flask REST API microservice running on port 5001.

Why Don't We Store Large Files On-Chain?

Blockchains are designed for small, high-value consensus transactions. Storing 100MB video/PDF files directly on-chain creates massive bloat. Instead, we store files in off-chain disk storage and record only their 32-byte SHA-256 hash on-chain!
