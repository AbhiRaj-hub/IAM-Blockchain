5. Vanilla JavaScript & Frontend

Clean & Lightweight Architecture

The frontend uses standard HTML5, CSS3, and modern Vanilla JavaScript (ES6) without bulky framework dependencies.

How the Frontend Communicates with the Backend

In js/api.js, a reusable apiRequest() helper wraps the browser's native fetch() API: 

async function apiRequest(endpoint, options = {}) {
  const token = localStorage.getItem('sih_token');
  const headers = { ...options.headers };

  if (token) {
    headers['Authorization'] = `Bearer ${token}`;
  }

  const response = await fetch(`http://localhost:5000${endpoint}`, {
    ...options,
    headers,
  });

  const data = await response.json();
  return { ok: response.ok, status: response.status, data };
}

Authentication Storage: localStorage

When a user logs in:

  • sih_token: Stores the JWT string.
  • sih_user: Stores user JSON (name, role, clearance level, DID).
