9. Bcrypt & JWT Authentication

Password Security: bcrypt Hashing

Passwords are never stored in plain text. When a user registers, Mongoose pre-save hook computes a salted bcrypt hash: 

userSchema.pre('save', async function (next) {
  if (!this.isModified('password')) return next();
  const salt = await bcrypt.genSalt(10);
  this.password = await bcrypt.hash(this.password, salt);
  next();
});

Token Generation: JSON Web Tokens (JWT)

Upon successful login, Express signs a stateless token containing the user's ID, role, and clearance level: 

const token = jwt.sign(
  { id: user._id, role: user.role, clearanceLevel: user.clearanceLevel },
  process.env.JWT_SECRET,
  { expiresIn: '7d' }
);

How the Token Protects Routes

The client attaches Authorization: Bearer <token> to every request. The authMiddleware.js verifies the signature and attaches req.user to the request object.
