3. Zero-to-One Local Laptop Setup Guide

Zero Complex Setup: This project includes a built-in Local Offline Storage Engine, meaning you do NOT need to install or configure MongoDB locally to run and demo the full system!

1. Environment Prerequisites

RuntimeRequired VersionVerification Command
Node.jsv18.0.0 or highernode -v
npmv9.0.0 or highernpm -v
Pythonv3.9 or higherpython --version or python3 --version

2. Cloning the Codebase

# Open your terminal (PowerShell / Command Prompt / Terminal)
git clone https://github.com/AbhiRaj-hub/SIH-2026.git
cd SIH-2026

3. Terminal 1: Launch Python Blockchain Service (Port 5001)

Navigate to the blockchain-service/ directory and install Flask:

# Windows / macOS / Linux
cd blockchain-service
pip install flask
python api.py
The Python service will start on http://localhost:5001 and automatically create chain_data.json with the Genesis block.

4. Terminal 2: Launch Node.js Backend & Web Server (Port 5000)

Open a new terminal window, navigate to backend/, install dependencies and start:

cd backend
npm install
npm start
What happens on startup?
If you haven't configured a remote MongoDB Atlas URI in backend/.env, the backend seamlessly activates the Local Offline Storage Engine (backend/data/db_store.json). All user accounts, DIDs, grants, and assets will work immediately without any timeout!

5. Open the Web Application

In your browser (Chrome / Edge / Firefox / Safari), open:

http://localhost:5000

6. 1-Click Login Testing

On the login page (http://localhost:5000/login.html), click any of the 1-click demo persona buttons:

  • Admin (Clearance Level 5): admin@shieldx.io / Admin@123
  • Manager (Clearance Level 4): manager@shieldx.io / Manager@123
  • Employee (Clearance Level 2): employee@shieldx.io / Employee@123
  • Auditor (Clearance Level 3): auditor@shieldx.io / Auditor@123
