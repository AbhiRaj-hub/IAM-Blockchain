The Dual-Storage Philosophy: Why MongoDB + Blockchain?

A frequent question asked by judges: "Why do you need both MongoDB and Blockchain?"

Feature Python Blockchain Ledger MongoDB Atlas
Role Cryptographic Source of Truth High-speed queryable mirror / index
Immutability 100% Immutable (SHA-256 Block Linking) Mutable (can be updated / indexed)
Query Speed Linear block scan (slow for search) Milliseconds (B-Tree indexed search)
What is Stored? DID hashes, access decisions, asset SHA-256 User profiles, usernames, file paths
