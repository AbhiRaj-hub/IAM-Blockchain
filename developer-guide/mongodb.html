6. MongoDB Atlas & Offline Fallback Engine

The Dual-Mode Storage Architecture

In production and offline environments, database connectivity may vary. Our backend implements a Resilient Proxy Storage Pattern: 

Mongoose Model Query (e.g. Identity.find().sort())
                     |
            Is MongoDB Connected?
           /                     \
        YES                       NO
        /                           \
Mongoose Driver            Local JSON Storage Engine
(MongoDB Atlas)            (backend/data/db_store.json)

The 5 Core Collections

1. `users`

Stores registered usernames, email, bcrypt password hash, role (ADMIN, EMPLOYEE, AUDITOR), clearance level (1–5), and assigned DID.

2. `identities`

Searchable index of all issued DIDs with credential IDs and blockchain block indices.

3. `access_grants`

Active and revoked resource permissions granted to specific DIDs.

4. `access_logs`

Audit trail of all clearance evaluations, storing resource, decision (ALLOWED / DENIED), reason, and mined block index.

5. `assets`

Digital document token records storing filename, version, on-chain SHA-256 hash, allocated owner DID, and block anchor index.
