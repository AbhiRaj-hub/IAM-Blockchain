8. REST API Endpoint Reference

1. Authentication Endpoints

MethodEndpointAuthDescription
POST/api/auth/registerPublicRegister new user
POST/api/auth/loginPublicLogin & get JWT token
GET/api/auth/meBearer JWTGet current profile

2. Identity (DID) Endpoints

MethodEndpointAuthDescription
GET/api/identityBearer JWTList all issued DIDs
POST/api/identityAdminIssue on-chain DID credential
POST/api/identity/:did/revokeAdminRevoke DID on-chain

3. Clearance & Access Control Endpoints

MethodEndpointAuthDescription
POST/api/access/requestBearer JWTClearance check & on-chain audit log
POST/api/access/grantAdminAnchor explicit permission grant
POST/api/access/revokeAdminRevoke permission grant
GET/api/accessAdmin/AuditorList all active grants

4. Digital Asset & SHA-256 Endpoints

MethodEndpointAuthDescription
POST/api/assets/uploadBearer JWTUpload file & anchor SHA-256 to blockchain
GET/api/assetsBearer JWTList all anchored assets
POST/api/assets/:id/verifyBearer JWTVerify file on disk against blockchain hash
POST/api/assets/:id/tamper-demoAdminSimulate 1-byte file modification for demo

5. Audit & Blockchain Telemetry

MethodEndpointAuthDescription
GET/api/auditAdmin/AuditorGet indexed audit log & raw chain txs
GET/api/audit/statsBearer JWTDashboard counters & chain height
GET/api/blockchain/statusBearer JWTRun cryptographic chain integrity validation
GET/api/healthPublicSystem health check
